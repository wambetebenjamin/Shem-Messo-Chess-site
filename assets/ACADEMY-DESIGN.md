# Chess Kenya source-inspired academy pages

Reference supplied by the user:
https://github.com/wambetebenjamin/Shem-Messo-Chess-site/blob/main/view-source_https___chesskenya.co.ke.html

The supplied file is a saved Chrome view-source table, not a ready-made template. The source text was extracted for inspection. Its external CSS/image files were not included in that saved document, so this is a clean adaptation of its layout and declared typography, not a claim of pixel-identical rendering.

The source has a white dropdown header, full-width photographic carousel, three-column highlight strip, image-and-panel About section, light section backgrounds, grouped content and a multi-column footer. It declares Open Sans, Raleway and Poppins. `academy-pages.css` adapts these cues consistently across all nine main academy pages, with pale title/breadcrumb bands for detail pages and responsive content/form/card layouts.

Our content, logo, navy/blue brand palette, original photos and verified social/contact destinations remain. The Home highlight strip uses real learning/play/joining links rather than importing unverified federation counts. Home remains short; officials remain only on About. No CKF identity, federation history, league standings, partners, awards, news, contacts, login backend, CSRF token, Blazor framework, tracking code or third-party CDN is imported. The original reference's carousel interval is not adopted: our previously requested four-second hero/staff timing remains.

The guided registration and official form embeds, optional push, FAQs/private feedback, authenticated games/public puzzle, product descriptions, category filters, quick-look/share/enquiry actions and accessible dropdowns are preserved. Contact details are in call/email/WhatsApp destinations, not printed as personal details. Functional control outlines remain; decorative divider lines do not.

The older PCA homepage comparison remains independent and does not load this stylesheet. Local font provenance/licenses are in `academy-fonts/README.md`. All Node/HTTPS/persistence and external-provider limitations described in the main README still apply; a visual adaptation does not provide those backends on static hosting.

## Latest refinement

The user subsequently requested less repeated footer content and balanced, animated lettering. The grouped reference-style footer has therefore been condensed to three links, five labelled icons, a logo and copyright. Headings no longer use forced line breaks; fluid sizing and balanced wrapping avoid narrow word ladders. Brief lettering and optional native page transitions enhance relevant text without looping, splitting words, delaying navigation or compromising reduced-motion/no-JavaScript reading.
