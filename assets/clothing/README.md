# Academy clothing

These transparent product cutouts come from the user-supplied `WhatsApp Image 2026-10-14 at 12.04.54 PM.jpeg` on main. Only the surrounding background was masked; clothing and printed artwork remain from that supplied image. No unseen rear artwork or additional variants are invented.

The catalogue uses the photographs with short product names and an enquiry button. `showcase.js` occasionally applies a brief, staggered fold/swipe-return effect; it also responds to horizontal swipes. It stays still while an item is hovered or its enquiry has focus. Motion can be paused, respects reduced motion, and stops offscreen or in hidden tabs. All products remain visible with JavaScript disabled. No renderer, canvas, Three.js, CDN, or backend is needed for the showcase. Enquiries use the existing Contact flow.
