# Template preview fonts

Nunito (600 and 800) and Raleway (600), Latin WOFF2 subsets, are copied from
`@fontsource/nunito` and `@fontsource/raleway`. Both are licensed under the SIL
Open Font License; the license files in this folder are included for attribution.
The supplied PCA source declares these families in its OceanWP typography.
They are served locally; the preview makes no requests to Google Fonts or PCA.
