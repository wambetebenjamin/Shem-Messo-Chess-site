# Local academy typography

The user-supplied saved Chess Kenya source explicitly references Open Sans, Raleway and Poppins. These Latin WOFF2 subsets are vendored from `@fontsource/open-sans`, `@fontsource/raleway` and `@fontsource/poppins` to use those families without external font requests.

- Open Sans 400, 600, 700: body and supporting text.
- Raleway 600, 700: titles and branding.
- Poppins 400, 500, 600: navigation and small interface labels.

All three families use the SIL Open Font License. Their full license files are included here. The files are static assets; the packages are not runtime dependencies.
